# ULTRON Interface Preview

This is the first UI-only phase of ULTRON, added alongside the existing JARVIS Telegram bot.

## Run
Open `index.html` in a modern browser. Chrome or Edge is recommended for browser speech recognition.

## Included
- Cinematic responsive crimson interface and animated CSS core.
- Local chat preview with ULTRON-style placeholder responses.
- Browser speech input where supported.
- Browser text-to-speech where supported.
- Explicit status indicators showing that the model and execution tools are not connected.

## Not included yet
- No AI model/API connection.
- No GitHub or repository access.
- No filesystem, terminal, coding, publishing or autonomous execution.
- No real agent memory.

This is intentionally a safe visual and interaction prototype. Connect a model only in a later phase, after reviewing the backend design and access boundaries.
